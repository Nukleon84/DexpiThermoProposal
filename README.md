# DexpiThermoProposal
A proposal for a DEXPI profile to exchange information about thermodynamic property data

Contains the example files explained in the blog post https://nukleon84.github.io/ChemicalCode/journal/Exchanging-Thermodata-with-DEXPI.html

Presented at the DECHEMA PEMT conference in November 2026 in Karlsruhe.
